# 宏观 → 行业：零件替换与行业专属信号

宏观模型分析的是"一个国家所有人的交易总和"。行业分析要做的不是简单类比，而是**在同一个因果结构里换一套观测装置**：把"债务"换成"产能与杠杆"，把"央行"换成"政策制定者+下游议价权"，把"信贷可得性"换成"账期与融资窗口"。

---

## 一、零件替换总表

| 机器零件 | 宏观口径 | 行业口径 | 行业观测指标 |
|---|---|---|---|
| 交易 | 买方用货币+信用换商品/服务/金融资产 | 下游客户采购、行业内部的设备与产能交易 | 订单量、招标金额、成交量 |
| 支出总额 | 消费+投资+净出口 | 下游客户的采购预算总额 | 行业市场规模（金额口径，非台数口径） |
| 价格 | 支出 ÷ 销量 | 行业均价、加工费、单位售价 | 行业价格指数、吨毛利、加工费 |
| 信贷 | 银行信贷、债券 | 贷款、债券、股权、**政府补贴**、**供应链账期**、预收款 | 有息负债增速、票据结算占比、DSO/DPO、合同负债 |
| 债务负担 | 债务/GDP | 有息负债/EBITDA、资产负债率 | 行业资产负债率、利息保障倍数 |
| 央行 | 中央银行（利率+基础货币） | 政策制定者（补贴/准入/环保/信贷窗口）+ 下游大客户 | 政策文件、补贴退坡节奏、大客户招标规则 |
| 利率 | 政策利率、市场利率 | 综合融资成本、行业风险溢价 | 行业债券发行利率、贷款利率 |
| 生产率 | 人均产出、TFP | 单位成本、良率、规模效应、开工率 | 单位成本曲线、人均产值、产能利用率 |
| 抵押物 | 房产、土地、股票 | 产线设备、厂房土地、产能指标 | 二手设备价、产能指标成交价、重置成本 |
| 长期债务周期 | 75-100 年债务超级周期 | **产能周期**（Capex 潮起潮落，7-10 年） | 在建工程/固定资产、Capex/折旧、新增产能投放 |
| 短期债务周期 | 5-8 年信贷周期 | **库存周期**（基钦周期，3-4 年） | 产成品库存天数、渠道库存月数 |
| 去杠杆 | 违约、重组、印钞 | 产能出清、破产重整、并购整合、价格战 | 亏损企业占比、破产重整数量、CR5 |
| 和谐去杠杆 | 名义增长>利率，债务比下行 | 产能出清完成、集中度提升、价格回到现金成本之上 | 行业利润率修复、头部企业现金流 |

## 二、行业版比宏观版多出来的四个信号

宏观有央行和统计局，行业没有。行业要靠这四组"替身指标"来读信贷条件与债务负担。

### 信号 A：账期——行业内部的"影子信贷"

原理：一个人（企业）的支出是另一个人（企业）的收入。产业链上，上游允许下游赊账，等于**上游向中游凭空创造了信贷**。账期拉长，就是链条在自我加杠杆；账期突然收缩，就是信贷消失。

| 指标 | 含义 | 读法 |
|---|---|---|
| 应收账款周转天数（DSO） | 上游给下游的信贷规模 | 全行业 DSO 连续 2-4 个季度上升 → 下游现金流紧张，链条在加杠杆 |
| 应付账款周转天数（DPO） | 中游占用上游资金 | DPO 大幅上升 → 弱势环节被挤压，行业议价结构恶化 |
| 现金转换周期（CCC） | DSO+存货天数−DPO | 上升 → 全行业真实占用的营运资金在扩张，隐性债务负担加重 |
| 票据结算占比 | 现金支付能力 | 票据/商票替代现金的比例上升 → 产业链信用在下沉 |
| 合同负债/预收款 | 下游预付意愿 | 逆势上升是强需求信号；下滑是需求转弱的领先信号 |

**判读要点**：账期是**顺周期变量**——景气时人人都愿意给账期，看起来"生意很旺"；一旦某一家出问题，全链条同时收紧，这就是行业版"信贷消失"的瞬间，往往比价格下跌更早、更猛。

### 信号 B：产能——行业版的"债务"

产能一旦建成就是沉没的，且必须靠持续的现金流养活。因此**产能 = 行业的刚性负债**，扩产冲动 = 加杠杆，产能退出 = 去杠杆。

| 指标 | 含义 | 读法 |
|---|---|---|
| 产能利用率 | 供需缺口的直接读数 | 长期低于 75% → 过剩；高于 85% 且价格加速 → 过热 |
| 在建工程/固定资产 | 已承诺但未投产的产能 | 该比值抬升 → 未来 1-2 年供给压力在路上（领先指标） |
| Capex / 折旧 | 扩产的相对强度 | >1.5 通常意味着净扩产；连续高于行业需求增速 → 埋下过剩 |
| 新增产能公告 | 最前瞻的信号 | 集中出现 → P3 过热的确认信号，也意味着 18-30 个月后的价格战 |
| 开工率 | 短期供给弹性 | 开工率低但价格涨 → 供给受行政或原料约束，价格弹性大 |

**判读要点**：产能周期的传导有明确时滞——**今天的高 Capex 是三年后的低价格**。看到行业集体扩产且股价大涨时，真正该问的是"这些产能哪一年投产"。

### 信号 C：库存——行业版的"短期债务周期"

库存周期 3-4 年，是行业分析中频率最高、最可操作的周期。核心不是库存绝对水平，而是**库存与销售的相对变化**（见 `indicators-playbook.md` 的四象限表）。

| 指标 | 读法 |
|---|---|
| 产成品库存同比 vs 营收同比 | 库存增速超过营收增速 → 被动补库，最危险象限 |
| 库存周转天数 | 突破历史区间上沿 → 降价压力积累 |
| 渠道/经销商库存月数 | 高于 2 个月通常意味着一轮去库存；家电/汽车/工程机械尤甚 |
| 在手订单/存货比 | 下降 → 后续收入承压 |

### 信号 D：结构——集中度与亏损面

行业周期的终点不是价格反弹，而是**结构出清**。这是判断行业版"去杠杆是否完成"的唯一可靠依据。

| 指标 | 读法 |
|---|---|
| 亏损企业数占比 | >30% 且持续 → 出清进行中；回落至 <15% → 出清接近完成 |
| CR5 / CR10 | 上行 → 尾部退出、龙头整合；停滞 → 出清不彻底，价格战会反复 |
| 行业毛利率分布（头部 vs 尾部） | 分化扩大 → 尾部在失血；同步修复 → 周期反转确认 |
| 破产重整/兼并数量 | 集中出现是 P5 的确认信号，也是底部区域的特征 |
| 新进入者数量 | 回升 → 下一轮过剩的种子，P2 后期需警惕 |

## 三、行业去杠杆的三种形态

宏观去杠杆有四件工具（紧缩/违约重组/财富再分配/印钞）。行业没有印钞权，只有三种路径：

| 形态 | 机制 | 典型特征 | 出清速度 |
|---|---|---|---|
| **价格战出清**（市场化） | 价格跌破现金成本，尾部现金流断裂退出 | 全行业亏损、龙头也亏、现金成本线成为价格地板 | 慢，2-4 年，最痛苦 |
| **行政去产能**（政策主导） | 环保、能耗、准入标准强制关停 | 政策文件密集、指标交易、开工率骤降 | 快，6-18 个月，但易反弹 |
| **并购整合**（资本主导） | 龙头逆周期收购，产能不消失但集中度上升 | CR5 快速抬升、行业负债向龙头集中 | 中速，价格修复较慢但更持久 |

**判断"和谐去杠杆"在行业里是否发生**（对应宏观的"名义增长>利率"）：

```
行业价格 ≥ 行业现金成本  → 全行业能活，但不足以覆盖折旧 → 僵持
行业价格 ≥ 全成本（含折旧）→ 具备再投资能力 → 真正修复
行业 ROIC ≥ WACC          → 资本愿意重新进入 → 新周期起点
```

三档依次递进。**价格站上现金成本只是止跌，站上全成本才是反转**——这一步最常被误判。

## 四、行业生命周期 × 周期阶段：二维定位

同一套周期刻度，在不同生命阶段的行业里读法完全不同。分析任何行业前先定位它落在哪一格。

| 生命周期 | 主导变量 | 周期读法 | 常见误判 |
|---|---|---|---|
| **导入期** | 技术路线、渗透率 | 债务周期基本不适用；看技术迭代与资本供给 | 把融资窗口当需求 |
| **成长期** | 渗透率 S 曲线 | 周期表现为"渗透率斜率 × 产能投放节奏"，波动剧烈但趋势向上 | 把渗透率提升当周期上行；把补贴退坡当周期见顶 |
| **成熟期** | 供需缺口、库存、Capex | **本模型的主场**，库存周期与产能周期清晰可辨 | 忽视需求侧的替代品侵蚀 |
| **衰退期** | 需求长期下移 | 所谓"复苏"多为产能出清带来的价格反弹，不是需求回归 | 把出清反弹误判为周期反转 |

**成长期行业的特殊提醒**：渗透率从 5% 到 50% 的过程，需求增速会天然高于产能增速，表现为"永远缺货"；此时价格高、扩产猛、杠杆升，看起来像 P3 过热，其实可能只是 S 曲线的中段。**判据是渗透率位置，不是价格动量**。真正危险的是渗透率进入 50%-70% 的减速区间，而产能投放正处高峰——那才是成长期的"长期债务顶峰"。

## 五、常见陷阱

1. **把渗透率提升当周期上行** → 用 S 曲线解释，别用周期解释
2. **把政策补贴当需求** → 补贴是信贷，退出时就是去杠杆；要问"补贴退坡后谁还买"
3. **把库存周期当产能周期** → 库存周期 3-4 年可修复，产能周期 7-10 年不可修复，对策完全不同
4. **只看价格不看成本线** → 价格跌破现金成本才是真出清开始，之前的下跌只是利润压缩
5. **用行业均价掩盖结构分化** → 龙头赚钱、尾部亏损的"均价企稳"是假底部
6. **忽略下游议价权** → 行业"央行"可能是下游大客户（如整车厂之于零部件），其招标规则变化等于一次加息
7. **低估在建工程的时滞** → 看到供给过剩时，产能往往还有一半没投产
