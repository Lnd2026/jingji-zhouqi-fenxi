# 经济与行业周期分析（经济机器框架）

一个用于诊断**宏观经济周期**与**行业周期**的 Agent Skill。把达利欧《经济机器是怎样运行的》里的因果链，从"一段讲解"改造成"一套可执行的诊断协议"。

它回答三个问题：

1. 现在处于周期的哪个位置？
2. 这个位置还能撑多久？（债务负担与偿债成本的可持续性）
3. 接下来会怎么走、政策还有多少牌？

支持两份口径：**宏观**（国家/地区/全球）与**行业**（落到品类与产业链环节）。

---

## 核心设计

### 一、五个必答问题

所有分析都必须用数字回答这五问，答不出就不许下结论。

| # | 问题 | 宏观口径 | 行业口径 |
|---|---|---|---|
| Q1 | 支出靠收入还是靠借？ | 社融增量 ÷ GDP 增量 | 有息负债增速 vs 营收增速 |
| Q2 | 债务负担往哪走？ | 债务/GDP 的分子分母赛跑 | 有息负债/EBITDA、资产负债率 |
| Q3 | 融资成本跑得赢增长吗？ | 名义利率 vs 名义 GDP 增速（r−g） | 综合融资成本 vs ROIC |
| Q4 | 利率还有多少空间？ | 政策利率离零的距离、实际利率 | 政策工具还剩几张牌 |
| Q5 | 抵押物在涨还是在跌？ | 房价、股价、土地成交 | 产能资产估值、二手设备价 |

**Q4 与 Q5 是分水岭**：Q4 空间耗尽 + Q5 转跌 → 已进入去杠杆；否则只是普通收缩。这一步判错，后面所有政策推演都会反。

### 二、六阶段判定

宏观与行业共用一套刻度，每档 3–6 条可观测判据：

| 阶段 | 宏观特征 | 行业特征 |
|---|---|---|
| **P1 修复** | 信贷增速由负转正；库存去化到低位；价格环比止跌 | 开工率自底部回升；亏损面收窄；几乎没人扩产 |
| **P2 扩张** | 信贷扩张；名义增长>融资成本；通胀温和 | 量增价稳；订单>库存；零星扩产 |
| **P3 过热** | 通胀加速；杠杆率快速上行；资产价格脱离基本面 | Capex/折旧显著抬升；在建工程大增；账期开始拉长 |
| **P4 收缩** | 库存高位；价格转跌；但利率仍有下行空间 | 订单下滑；价格仍高于现金成本；Capex 推迟 |
| **P5 去杠杆** | 利率接近零且失效；债务/收入比历史高位；违约上升 | 全行业亏损；价格低于现金成本；产能被动退出 |
| **P6 再平衡** | 名义增长>利率；债务/收入比下行 | 产能出清完成；集中度提升；价格回到成本线之上 |

### 三、宏观 → 行业的零件替换

不是类比，是换一套观测装置。行业没有央行和统计局，所以补了四组"替身指标"：

- **账期 = 行业内部的隐性的信贷**：DSO 拉长，等于产业链在自我加杠杆
- **产能 = 行业的刚性负债**：今天的 Capex 是三年后的低价格
- **库存 = 行业版短周期**：看库存与销售的相对变化，不看绝对水平
- **集中度与亏损面 = 出清是否走完的唯一可靠依据**

### 四、三条法则校验

- 债务增速不得超过收入增速
- 收入增速不得超过生产率增速
- 尽一切提高生产率

三条全过，结论才敢写"可持续"。

## 使用

安装后在对话里直接描述需求即可触发，例如：

- 「分析一下钢铁行业现在处于周期什么位置」
- 「这轮下行是普通衰退还是去杠杆？」
- 「光伏什么时候能产能出清？」
- 「当前经济环境适合配置什么」

技能会走完整流程：界定刻度 → 画支出闭环 → 拆三股动力 → 五问诊断 → 阶段定档 → 情景推演 → 十条跟踪看板。

## 诊断脚本

`scripts/cycle_diagnostics.py` 把需要反复手算的派生指标固定成代码。只用标准库，无依赖。

```bash
# 生成填数模板
python scripts/cycle_diagnostics.py --sample > indicators.json

# 填完后跑诊断
python scripts/cycle_diagnostics.py indicators.json

# 输出 Markdown 表格（方便贴进报告）
python scripts/cycle_diagnostics.py indicators.json --md
```

输出包含 9 个派生指标（r−g、信贷加速度、库存-销售缺口、产能缺口、政策空间等）、六阶段规则命中表与判定结论。

判定规则内置两道防呆：一是**最少可用判据门槛**（4 条判据需至少 3 条有数据），避免"1 条命中 → 100% 达标"的假结论；二是数据不足时明确报"证据不足"，不用猜测填充。

## 几个刻意的取舍

**为什么不用 PEST / SWOT？** 那是清单，不是模型。清单能让你"覆盖全面"，但不能告诉你下一步会发生什么。这里要的是一条能推演的因果链。

**为什么反复强调"收缩 vs 去杠杆"？** 因为这是整个框架里唯一能改变对策判断的分叉。前者降息就能救，后者降息失效，只剩四种结构性办法。

**为什么行业分析要换零件而不是套用？** 行业的"债务"是产能，"央行"是政策制定者加下游议价权。直接套宏观指标会得出"行业没有债务周期"的错误结论。

**为什么给不确定性和反证留专门一节？** 这个模型最可靠的能力不是预测时点，而是排除不可能的解释。承认它会在哪错，比给一个漂亮结论更有用。
